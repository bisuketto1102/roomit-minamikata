# 朝の読み取りチェックの記録

毎朝9:15の定期実行「朝の読み取りチェック」が、紙（写真・PDF）と保存した内容のずれを1日1回ここに足す。月曜13:30の「週の読み取り振り返り」がこれを読んでまとめる。
コードは直さない。書くのはこのファイルだけ。清掃員の名前は書かない。

書き方（新しい日を下に足す。同じ日にもう一度動いたら、その日の欄を書き直す）：

```
## yyyy-MM-dd
- 結果：ずれ n件（m室を確認）／要確認 k件（あれば）
- 部屋 項目　紙: … ／ 保存: …（ずれ1件1行、全部）
- 判読できない：部屋…（あれば）
- 見られなかった：…（あれば）
```
